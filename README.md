# 深入聊聊 AI Agent

> 这是一本关于 AI Agent 的书，我不想从如何手把手的带着你搭建一个可用的 Agent 入手来写这个东西，因为这样的书已经很多了！更为关键的是，step by step 的方式，你最终只能得到一个 Demo，毫无工程价值。我希望你能在阅读这本书后，从原理上知道一个工程化的 AI Agent 到底是怎么运作的。至于如何用代码去实现，呵呵！我相信你基本上已经不会自己手写代码了！

先啰嗦这么多吧，书的内容正在编写和校对中，格式比较混乱，如果有什么意见，欢迎随时批评。
